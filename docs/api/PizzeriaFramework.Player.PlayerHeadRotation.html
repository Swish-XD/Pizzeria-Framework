Namespace
PizzeriaFramework.Player

Manages the player's panoramic head rotation utilizing realistic inertia formulas based on mouse placement coordinates. Includes integrated asynchronous pipelines for scripted object gaze tracking and smooth dynamic camera field-of-view (FOV) transitions.

[RequireComponent(typeof(Camera))]

ChangeFovAsync(float, float, bool)

Asynchronously transitions the hardware field-of-view (FOV) focal angle properties using smooth linear step calculations. Useful for cinematic zoom effects, paranoia mechanics, or camera feed magnification layers.

Example of use:

playerRotation.ChangeFov(45f, 0.5f, false); // Zooms scene views in over half a second
public UniTask ChangeFovAsync(float endFov, float duration, bool instant)
