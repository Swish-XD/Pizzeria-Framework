GetAILevelForCharacter(string)

Linearly searches the profile collection to locate the configured AI difficulty level by a character's string identity key.

Example of use:

int level = profile.GetAILevelForCharacter(animatronic.ID);
public int GetAILevelForCharacter(string id)

Parameters

id string

The unique string identifier of the target animatronic character.

Returns

int

The assigned AI difficulty level integer (0-20), or -1 if the character is not registered in this profile.
