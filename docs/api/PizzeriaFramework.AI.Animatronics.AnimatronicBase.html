Class AnimatronicBase

Namespace
PizzeriaFramework.AI.Animatronics
Assembly
PizzeriaFramework.Runtime.dll

Base abstract class for all animatronics in the framework. Manages the asynchronous AI tick loops, components injection, modular strategy handlers, movement, and event subscriptions.

[RequireComponent(typeof(Animator))]
public abstract class AnimatronicBase : MonoBehaviour, IAnimatronic
