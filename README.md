# Pizzeria Framework

**Pizzeria Framework** is a comprehensive, production-ready toolkit designed for creating atmospheric, point-and-click survival horror games. It provides all the core systems and editor utilities needed to build a tense, terrifying experience from scratch.  

## Key Features
* **Modular Interface-Based AI:** Powered by a high-performance tick system for predictable, highly optimized, and easily extendable animatronic behavior. 
* **SOLID Architecture:** Clean, decoupled, and highly extendable codebase designed according to industry best practices. 
* **Event-Driven Systems:** Fully decoupled logic using robust event structures to minimize tight coupling.
* **Zero-Allocation Mindset:** Highly optimized code written to reduce garbage collection (GC) spikes and ensure smooth mobile/desktop performance. 
* **Custom Editor Utilities:** Features an isolated *Animatronic Pose Studio* directly within the Scene View to bake custom animations on the fly.
